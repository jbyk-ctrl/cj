# チルドレンジャパン Webサイト リニューアル デモ

`チルドレンジャパン_Webサイト制作共有資料.pptx` の企画に沿った、リニューアル後サイトイメージの確認用デモです。
本番サイト（childrenjapan.com）には一切手を加えていません。

## 収録ページ（企画書の全12ページ中、内部限定の「制作ガイド」を除く11ページ）

- `index.html` — トップページ
- `government.html` — 自治体・公的機関向け
- `business.html` — 企業・生産者向け
- `services.html` — サービス
- `projects.html` — 実績・事例
- `furusato-iimono.html` — ふるさと"いいもの"展
- `kyodo-dinner.html` — 郷土でぃなー
- `wabitabi.html` — WABITABI
- `about.html` — 私たち（ARCH PROJECTの沿革・会社概要を含む）
- `insights.html` — 活動レポート・知見
- `contact.html` — お問い合わせ（送信機能なし）

「制作ガイド」は企画書内でも「公開サイトでは非表示」の内部共有用ページのため、本デモには含めていません。

## 素材について

- 写真は childrenjapan.com の会社概要ページ、および共有いただいた企画書内の現場写真を再利用しています。
- 上記でカバーできない箇所はプレースホルダー枠を使用し、実在しない写真の生成は行っていません。
- 各ページの「STEP」フロー等、企画書に具体的な記述がなかった部分は草案です。内容の確定が必要です。
